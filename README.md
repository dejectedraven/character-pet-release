# Character Pet

Windows 桌面 AI 角色桌宠。当前角色：散兵 Q 版。

> 这是**分发仓库**，只放安装包、安装说明、版本更新说明与许可声明；不包含源码，也不包含角色包或解锁码。
> 解锁码由发布者单独提供，每个码绑定一台机器。

## 下载

- 最新安装包：[Releases](../../releases/latest)
- 当前版本：**v0.2.11**
- 文件：`CharacterPet-Setup-0.2.11.exe`（约 231MB）
- SHA256：`5ddb83362bf4a055eb45b8d6fb2c31d86467ac3edfb49ddfd57b12cadae8b664`
- 系统：Windows 10/11 x64；无需管理员权限；建议 4GB+ 内存、500MB+ 磁盘。

## 安装

1. 下载 `CharacterPet-Setup-0.2.11.exe`。
2. 双击运行。Windows SmartScreen 可能提示未知发布者，选择“更多信息 → 仍要运行”。
3. 安装到 `%LOCALAPPDATA%\Programs\CharacterPet`，自动创建桌面与开始菜单快捷方式并启动。
4. 安装包不安装系统服务，不写系统目录，不需要管理员权限。

## 第一次启动

### 1. 解锁码

安装包**不内置基础角色**。首次启动必须输入发布者提供的解锁码：

- 服务端验证后，只下载该码对应的加密角色包；安装包本身不包含角色。
- 一码绑定一台机器；同一台机器重装可再次激活；换机需由发布者重置。
- 角色包加密，下载后先校验再安装。
- 新形象使用新的独立解锁码；从托盘菜单“解锁新形象…”添加。

### 2. 网络要求

激活请求通过 relay 中转（主站 Netlify，备用站 Cloudflare Pages，客户端按序自动回退），角色包由 GitHub Release 分发，国内普通网络可直接使用，不需要自己配置代理。第一次激活请保持网络畅通；角色包约 10.8MB。

### 3. 对话后端

默认选择 **DeepSeek API**：

- API Key：`sk-...`
- 模型：默认 `deepseek-chat`
- Base URL：默认 `https://api.deepseek.com`

也可以：

- **本机 Ollama**：先启动 Ollama，点“检测本机 Ollama”，选择/填写模型（默认 `qwen3.5:9b`）。
- **暂不配置**：桌宠仍可启动，动作/动画正常；对话关闭。之后从托盘“对话 / API 设置”重新配置即可恢复。

API Key 只保存在本机桌宠数据目录的 `llm.json`（位于 `%APPDATA%\CharacterPet\home\` 下），不会上传到本项目服务器。

### 4. 启动后

- 主程序常驻系统托盘；桌宠是独立透明置顶小窗。
- 托盘菜单：对话 / API 设置、闲聊 / 任务模式、语音（F5）、解锁新形象、打开数据目录、退出。
- 点桌宠打开右键菜单：打开 OpenCode、查看余额、碎碎念、对话、回到初始位置等；可拖动、点击互动。

## 自动更新

v0.2.0 起，首次成功激活后会把解锁码用 Windows 本地加密保存（不保存明文），启动时和每 6 小时自动通过授权服务器检查角色包版本：

- `SHA256` 没变：不下载。
- 有新版本：自动下载并替换角色包，然后重启桌宠服务。
- 更新不需要重新输入解锁码；解锁码过期/吊销或本地加密不可用时才需要手动重新输入。

## 闲聊 / 任务模式

托盘 →“闲聊 / 任务模式”：

- **闲聊**：使用桌宠当前人设、记忆和 DeepSeek/Ollama 配置，和右键对话共用 `memory.json`。
- **任务**：调用本机 `opencode serve`，选择工作目录后交给 OpenCode CLI 执行；可选择模型、停止任务、新建会话。
- 任务模式需要本机安装 `opencode` CLI；未安装时聊天仍可用。
- 任务完成后摘要会回到桌宠气泡；执行日志留在任务面板。

## 语音

发布包**不内置** F5-TTS/Torch 模型，但内置一键安装代码（`uv.exe`、`f5_tts_server.py`、`voice-install.ps1`）。

首次安装：

1. 托盘 →“语音（F5）”，或首次设置里的“语音（F5）安装 / 管理”。
2. 点“一键安装 / 修复 F5”，确认下载（约 3–4GB）。
3. 安装器会下载 Python 3.10、CUDA PyTorch、F5-TTS 和模型，完成后自动启动 9881。

没有语音服务时文字对话与动作仍可用。F5 停顿：句间 0.34s，逗号/顿号后 0.18s，哼/呵/哈/嘿/切/啧等语气词后 0.56s；括号中的内心话不读。碎碎念会朗读，气泡 9 秒；聊天气泡 18 秒。

## 数据与隐私

所有用户数据在本机：

```text
%APPDATA%\CharacterPet\
  home\                      桌宠数据目录
    llm.json                 对话后端配置
    memory.json              对话记忆
    main-config.jsonc        角色实例配置（解锁后写入）
  packs\                      角色包
  unlocked.json               已解锁形象
  activation.json             本机激活记录
  license-code.bin            本机加密保存的解锁码（Windows DPAPI）
  server.log                  桌宠服务日志
  opencode.log                任务模式日志
```

- 不收集遥测；对话内容只发往你配置的 DeepSeek/Ollama；任务内容只发往本机 OpenCode 服务。
- 删除 `%APPDATA%\CharacterPet` 会清空记忆、解锁记录和角色包。
- 卸载：退出托盘程序，删除 `%LOCALAPPDATA%\Programs\CharacterPet`；数据目录可保留。

## 更新

- 新版安装包覆盖安装到同一目录，保留 `%APPDATA%\CharacterPet` 数据与解锁记录。
- v0.2.0 首次启动后会自动检查角色包更新；v0.1.x 用户需要重新输入一次解锁码来启用自动更新。
- 新形象/新皮肤会有独立解锁码；旧码不因更新失效。

## 已知限制

- 安装包不带基础角色；没有解锁码无法启动角色。
- 一码一机；换机需发布者重置，不提供自助换机。
- 任务模式依赖本机 OpenCode CLI 及其模型配置；默认模型不可用时会显示错误。
- F5 语音为空机全量下载，首次安装依赖网络，尚未覆盖所有网络环境。
- 请勿公开传播解锁码。
- H3 / Wan2.2 本地视频工作流仍是研究项，未包含在安装包内。
